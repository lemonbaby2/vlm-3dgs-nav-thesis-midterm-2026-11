## 3. 关键实现细节

### 3.1 新增独立模块（`x_planner_v2`，均可单测）
- `include/nav_light_map.hpp` / `src/nav_light_map.cpp`：读 `nav_light/`（`index.json`+`floors/<id>/{meta.json,grid.bin}`）、版本校验、`z→楼层`、世界↔格坐标、**单层粗栅格 A\***（8 邻域、禁贴角、unknown 默认禁行、代价可配）、`PlanAStarWithFallback`（严格失败→放宽 unknown）。
- `include/chunk_index.hpp` / `src/chunk_index.cpp`：读 `chunks/index.json`，`ChunksNear(x,y,r[,level])` 选块，`TilePath()` 定位瓦片（PCL-free）。
- `include/region_load_policy.hpp`：`ShouldReloadRegion`/`GoalWithinRegion`/`RegionRadiusForGoal`（位置触发策略，PCL-free）。
- `include/mini_json.h` / `src/mini_json.cpp`：极简 JSON DOM（从 x_nav 移植）。

### 3.2 A2：启动改读轻量层
- 参数 `nav_light_enable`（默认关）。`load_map` 中开启且产物/版本有效 → 只读 nav_light + 文件类数据（nav_points/obs/poses/ground_levels/semantic），**跳过全量点云/Vox/SDF/kdtree/ground graph**；否则回退全量。

### 3.3 A4/A5：区域细图按需加载与发布（方案A：双缓冲构建 + 临界区发布）
- `LoadChunkIndex`（随 `LoadNavLight`）；`LoadRegionCloud(x,y,radius,level)` 按索引加载相交瓦片 → 区域点云。
- `BuildRegionBundle(...)`：在**临时对象**上构建 `cloud/ground/Vox_map/SDFMap2D`（与全量加载同序）。
- `PublishRegionBundle(...)`：在 `map_publish_mutex_` 临界区内**就地整体替换** `map_cloud_/vox_map_/sdf_map_`，并 `kdtree_.setInputCloud`、`astar_planner_->updateMap`、`buildTrustedGroundClearance`、重建关键点/拓扑。`sdf_map_` 改 `shared_ptr`（读侧 `sdf_map_->` 不变）。
- 触发：位姿回调按 `region_refresh_distance_m` 节流；规划前确保区域覆盖目标。
- 参数：`region_load_enable`(false)、`region_lookahead_m`(80)、`region_refresh_distance_m`(5)。

### 3.4 A3：粗栅格全局规划（权威化）与跨层拼接
- 参数 `nav_light_authoritative`（默认关，仍需 `nav_light_enable`）。
- `BuildGlobalPathOnNavLight(start,goal)`：同层 → 粗 A\*；跨层 → `BuildCrossFloorCoarsePath`；成功后按 `dijskra` 同契约写 `global_path_` 并发布。
- `BuildCrossFloorCoarsePath`：`RobotPatch`/`ResolvePatchForPose`（先严格容差、再 `nav_light_patch_z_tolerance_m=0.8` 宽容差）→ 仍空则按 **nav_light 楼层→最近语义 floor patch**（`SemanticFloorPatchForNavLevel`）兜底；`FindSemanticPatchSequence` 取路线；**接近段用粗 A\***、**楼梯内部段用直线**（沿语义走廊）。
- **重规划统一入口** `BuildGlobalPathAuthoritativeOrFull`：把三处历史"重规划直接调 `dijskra`"改为**A3 优先、失败回退 `dijskra`**——修掉了"绿线生成后又被跨层失败的重规划清空"的问题。
- 参数：`nav_light_unknown_cost`/`nav_light_allow_unknown`/`nav_light_snap_cells`。

### 3.5 连通性加固（离线 + 生成侧）
- 生成侧 `ProductBakerOptions.nav_light_free_dilate_cells`：`free` 向 `unknown` 扩 N 格（不覆盖 occupied/stairs）。
- 消费侧 `PlanAStarWithFallback`（严格失败→放宽 unknown）。
- 工具 `tools/map_manage/nav_light_connectivity.py`：连通块/孤立块/最大块占比 + `--simulate-dilate` 定标 + `--self-test`（本地通过）。
- 实测：cf0930/cf09281658/cf09301 各层基本 1 连通块（“断连”未实际发生，稀疏更多是覆盖问题）。

## 6. 已知问题（本次搁置）

### 6.1 全局路径 z 不贴地面（建新图时解决）
- **现象**：绿线整体不贴合地面点云；中途偶有 z 跳变。
- **根因**：**该图 z 不自洽**——`nav_light` 层 `z_floor`（-0.68/1.92/5.32）与语义/地面 z（3.10/5.78）差 ~1m；且 `z_floor = 层 z_min + margin`（层底），非地面表面。
- **重烤无效**：`semantic_tool rebake` 前后层 z **完全一致**（确定性），问题在产品口径而非"产物旧"。
- 已尝试并把稳定版回退：路径**平滑、连续、连到终点**（仅 z 有系统偏差）；planner 侧不再强行"猜地面"。
- **结论/决定**：**记为期"建新图时解决"**（新图应统一 z 基准，使 nav_light 层 z 与地面/语义一致）。

### 6.2 其他
- 区域**缓存/预取**未做（`region_cache_mb`/`region_prefetch_chunks` 仅设计）。
- **大图/多层压测**未做（目前验证图 2~5 chunks、2~3 层）。
- **从未跑一次完整实车导航**（底盘锁定下只验证了路径生成与显示）。
- A3-3 强依赖 **reviewed 语义楼梯**；无楼梯的多层图（如 cf09211647 原状）跨层只能回退。
